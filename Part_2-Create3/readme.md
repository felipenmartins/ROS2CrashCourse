# Part 2 - Create3

This part contains activities to practice ROS concepts with the  [iRobot Create3](https://iroboteducation.github.io/create3_docs/) educational robot. 

- Overview of the Create3
- Activity 1 - IR sensors and LED pannel
- Activity 2 - Actions with the physical buttons   

## Setup Requirements

### Hardware
The demonstration platform used in this course is the [iRobot Create3](https://iroboteducation.github.io/create3_docs/) educational robot. 

If you do not have access to a Create3 robot, very similar activities can be created and demonstrated using the Gazebo simulation provided in the [Create3 Simulation Packages](https://github.com/iRobotEducation/create3_sim). However, this does require a powerful enough machine to comfortably run Gazebo.
